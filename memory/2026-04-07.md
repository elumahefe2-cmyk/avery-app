## OpenTXT - Media Agent webhook payload requirement

- Jacomo clarified the canonical Media Agent -> n8n handoff format.
- The payload sent to n8n must use a top-level JSON array containing a single object with exactly:
  - `headers`
  - `params`
  - `query`
  - `body`
- The actual OpenTXT content brief payload must live inside `body`.
- `body` must include `workflow`, `timestamp`, `source`, `briefId`, `researchBasis`, `researchSummary`, `brief`, `webhookUrl`, and `executionMode`.
- `researchBasis` should remain `competitor-first`.
- Do not send a bare object.
- Do not duplicate `webhookUrl` or `executionMode` outside `body`.
- Every outbound brief must include a generated `briefId` so returned renders can be matched reliably.
- Jacomo wants n8n to return a minimal payload centered on the video URL; the preferred minimal response is:
  - `briefId`
  - `videoUrl`
- The Media Agent should match returned videos to original briefs by `briefId`.
- This requirement was written into:
  - `creative/media-agent-system.md`
  - `creative/media-agent-prompt.md`
  - `creative/media-agent-template.md`
